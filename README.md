# Task Manager MERN

A full-stack Task Manager application built with:

- React.js
- Node.js
- Express.js
- MongoDB

## Features

- User Authentication
- Add Tasks
- Edit Tasks
- Delete Tasks
- Task Filtering
- Search Tasks
- Responsive UI

##how to run the project
-first run the client 
  In the project folder we change directory to client folder 
  and run project with command "npm run dev".
-open on crome "http://localhost:5173/"
-After that run server
   change directory to server and then project with "npm run dev".
